With the agy CLI (`agy acp`, 1.5.0), exact per-model-call tokens are in ~/.gemini/antigravity-cli/conversations/<sessionId>.db, table steps: agent steps step_type=15, metadata protobuf field 9 -> varint 2=uncached input, 3=output, 5=cache read (4 assumed cache write, unverified). PromptResponse.usage is present but turn-cumulative (input_tokens, output_tokens, cache_read_tokens). Live check 2026-11-05: two short Gemini 3.8 Flash turns (~8k prompt tokens) on a reused warm session showed cacheRead=0 both times, so implicit caching did not hit for small quick prompts.
