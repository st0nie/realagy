The inactivity guard (`inactivityMin` in `~/.pi/agent/realagy/config.json`, file-only, minutes) defaults to `0` = disabled, by the user's decision (it used to be 5 minutes and killed turns while a model silently generated one very large tool payload). `src/provider.ts` passes `deps.inactivityMin?.() ?? 0` on every `DriverTurnRequest`; `DEFAULT_INACTIVITY_MIN = 0` in `src/acp/driver.ts` (`#armIdle` returns when `idleMin <= 0`). `formatConfigSummary` prints `Inactivity timeout: disabled (default)` when unset, `disabled` for explicit 0, `<n> min` otherwise. A positive value re-enables it; parked pi tool calls and running native agy tools still pause it.
