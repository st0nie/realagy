When the user steers in Pi while an `agy acp` turn is parked on a `pi-bridge` MCP tool call (`stopReason: "toolUse"`), Pi's agent loop (`@earendil-works/pi-agent-core` `runLoop`) drains `steeringQueue` right after `executeToolCalls` and appends the steering `{ role: "user" }` message(s) (and any system updates) to `context.messages` strictly after the `{ role: "toolResult" }` message(s), then calls `streamSimple` (`reentry`).

`createStreamSimple` in `src/provider.ts` slices `context.messages` after the last resolved `toolResult` (`context.messages.slice(context.messages.lastIndexOf(result) + 1)`) and passes those trailing messages to `formatToolResult(result, trailing)` in `src/transcript.ts`. `formatToolResult` appends a `<pi-steering>` block (and any steering images, numbered after the tool's own images) to the MCP `BridgeResult` returned to `agy` (including for slow tools escalated via `bridge_poll_result`), without mutating `context.messages` so `warmAfterTurn` fingerprints remain exact for subsequent warm turns.
