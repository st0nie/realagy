How realagy keeps pi in charge of context despite agy's own auto-compaction. Implemented 2026-11-07 on branch fix/agy-compaction.

**Context windows** (`src/models.ts`)
- pi's `contextWindow` is agy's compaction limit (`max_token_limit`), not the raw 1M window.
- Live values come from `modelLimitsFromAgy()` and `withModelLimits()`. `fetchAcpModels(pid)` in `src/quota.ts` calls `GetAvailableModels` on the acp language-server port inside `discover()` in `extensions/index.ts`.
- Offline values come from `familyLimits()`: 256k for gemini-3.8/4 and claude, 80k for gpt-oss, 128k otherwise.

**Checkpoint data**
- `WarmSession` stores `contextTokens` (measured `usage.totalTokens`) and `overhead`. Overhead = the fresh session's first measurement minus `estimateInputTokens(seed)`, capped at 40k; the default is 15k.
- Both fields are persisted in `realagy-warm-session` entries.

**Planning** (`src/transcript.ts`)
- `planTurnFrom(..., veto)`: once a session's newest matching checkpoint is vetoed, every checkpoint of that session is skipped.
- `warmVeto` in `src/provider.ts` vetoes a session when:
  - agy compacted it: `firstCompactionIdx` finds a step_type 23. An older checkpoint is still accepted only if it lies before that step and below 50% of the limit.
  - it is in `sessions.retired`.
  - `rotationReason()` fires:
    - "agy-context-limit": used ≥ 80% of the limit and pi's fresh transcript saves ≥ 10%.
    - "pi-context-smaller": used ≥ 50% and the saving is ≥ max(25%, 16k).

**Mid-turn** (pi tool results arriving for a parked turn)
- `midTurnRotation()` checks for an agy compaction step, `sessions.rotateActive` ("pi-compacted", set by the extension's `session_compact` handler, which now keeps `sessions.step`), or a rotation reason.
- If any applies, the provider fails the pending bridge calls (`failAll`), runs `cancelActive`, then plans fresh. The fresh transcript includes the tool results.

**Other behaviour**
- `compactionLimit()` uses the agy limit even when the user's models.json raises the window.
- The `onRotate` callback triggers a UI notice only for "agy-compacted".
- `AGY_CLI_AUTO_COMPACT_OVERRIDE` defaults to "100%" in `extraEnv`. This currently has no effect on `agy acp`.

**Probes and live checks**
- Probes: `scripts/probe-compaction.mts`, `scripts/probe-rotation.mts`.
- Live gpt-oss check: rotation happened at 57k → fresh 6.7k, and the code word was recalled.
