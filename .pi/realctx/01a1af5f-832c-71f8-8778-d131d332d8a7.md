`agy --print /usage --output-format json` takes ~7–15s because `printmode.Run` cold-starts an in-process language server, reconciles all SQLite conversations in `~/.gemini/antigravity-cli/conversations`, and runs `printmode.waitForAuth` + `printmode.waitForEligibility` (multiple `loadCodeAssist`, `fetchAvailableModels`, and `ListExperiments` round-trips) before calling `ServerBackend.RetrieveUserQuotaSummary`.

Meanwhile, the long-lived `agy acp` process spawned by `realagy` already boots the in-process language server on the first `session/new` (during startup `listModels`) and logs its localhost HTTP port to `~/.gemini/antigravity-cli/log/acp-server-<timestamp>-<pid>.log`:
`Language server listening on random port at <port> for HTTP`

Sending `POST http://127.0.0.1:<port>/exa.language_server_pb.LanguageServerService/RetrieveUserQuotaSummary` with `Content-Type: application/json` and body `{"forceRefresh":true}` calls the exact same `CodeAssistClient.RetrieveUserQuotaSummary` in ~300ms (or <1ms with `{}` from cache), returning protojson `{ response: { groups: [{ displayName, description, buckets: [{ bucketId, displayName, description, window, remainingFraction, resetTime }] }], description } }`.
