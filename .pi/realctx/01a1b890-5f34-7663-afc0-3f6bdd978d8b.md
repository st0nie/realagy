In `src/transcript.ts`, `matchWarmPrefix` checks prefix/cwd/delta, and `planTurnFrom` selects the matching checkpoint with the smallest `delta.length`. If its effective history was rewritten (drops, summaries, compaction), it returns `{ kind: "context-sync", sessionId, maxStepIdx, ... }`; it never falls back to an older checkpoint or forks the DB. Cache-aware reclaim policy, thresholds, switch, and `context-reclaimed` fresh restarts were removed. Sync is always on; unsupported mappings fail closed instead of priming/replaying the transcript. `/tree` rewinds still match via `matchWarmPrefix`; later checkpoints are rejected as `history-shrank` / `history-diverged`.
