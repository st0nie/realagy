In `src/transcript.ts`, `matchWarmPrefix` matches prefix/cwd/delta before reclaim policy, and `planTurnFrom` selects the prefix-matching checkpoint with the smallest `delta.length` before running `applyReclaim` (`shouldReclaim`).

When the closest matching checkpoint on a branch exceeds the reclaim threshold, `planTurnFrom` returns `{ kind: "fresh", reason: "context-reclaimed" }` immediately instead of continuing to scan older checkpoints on the same branch (which previously matched an early checkpoint with `hidden < minShare`, forked `<sessionId>.db` via `resolveSessionAtStep` / `forkConversationAtStep`, busted the upstream conversation prompt cache, and replayed intervening turns as multi-part `pi://transcript-delta` priming prompts). `/tree` rewinds still match the target branch's latest checkpoint (`cp_k`) because checkpoints past the rewind fail `matchWarmPrefix` (`history-shrank` / `history-diverged`).
