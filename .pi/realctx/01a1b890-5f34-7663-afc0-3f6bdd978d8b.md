In `src/transcript.ts`, `matchWarmPrefix` checks prefix/cwd/delta. `planTurnFrom` prefers an exact match on a more preferred checkpoint that reaches at least as far; stale older checkpoint warm items may no longer describe rewritten native steps. Rewritten effective history (drops, summaries, compaction) uses `{ kind: "context-sync", sessionId, maxStepIdx, ... }` when appropriate; it does not simply return the first context-sync candidate. Cache-aware reclaim policy, thresholds, switch, and `context-reclaimed` fresh restarts were removed. Sync is always on; unsupported mappings fail closed instead of priming/replaying the transcript. `/tree` rewinds still match via `matchWarmPrefix`; later checkpoints are rejected as `history-shrank` / `history-diverged`. In `src/acp/trajectory-sync.ts`, an empty failed/aborted assistant message (`isEmptyFailedAssistant` in `src/transcript.ts`, WarmItem `failed: true`) maps optionally: if the prompt reached the model, it maps to agy's planner step; if sync or spawn failed first, it maps to no native step.
