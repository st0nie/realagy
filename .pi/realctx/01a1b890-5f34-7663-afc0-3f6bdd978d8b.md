`src/transcript.ts` `planTurn()` reuses only the current warm ACP session when its exact Pi transcript prefix and cwd still match. Normal turns send only appended user text or a `pi://transcript-delta`; a changed tool set is announced with `<pi-tools-update>` and does not force a rebuild. Any compaction, edit, rollback, `/tree`, divergence, missing session, or ambiguity creates a fresh ACP session with one prompt containing `<pi-system>`, bounded `<pi_history>`, and the newest live input verbatim. Budgets: 2,200,000 UTF-8 bytes unlocked, 160,000 locked; omit oldest history first, never truncate newest input, retain later assistant/toolResult messages, and use `EMPTY_INPUT_CONTINUATION` when there is no text. Fresh requests preserve current-turn extension injections exactly once; `persistentMessages()` filtering is only for warm-prefix bookkeeping. `DriverTurnRequest.fallback` holds the full replay for reopen failures.

`src/provider.ts` `recordWarm` records completed turns and aborted turns with `promptDelivered`; only settled snapshots are persisted through `onWarm` at `turn_end`. Parked native turns may be reentered only for exact-prefix warm plans. `restoreWarmSessions(branchEntries)` returns only the latest snapshot on the current Pi branch. `session_tree` clears the native cache unconditionally. There are no alternate checkpoint lists, `sessions.step`, `maxStepIdx`, trajectory synchronization, protobuf rewriting, native continuation patching, SQLite forks, or native checkpoint correctness dependencies. agy's SQLite store is read-only.

Usage: `src/acp/driver.ts` emits `step_usage` from agy SQLite steps (`step_type` 15, metadata field 9) at bridge calls and prompt end. `src/acp/step-usage.ts` opens short-lived read-only connections; failures degrade to undefined. Provider usage sync preserves exact per-call input/cacheRead/output and latest-call context. Sibling parallel-tool messages use `siblingUsage`; `UsageMeter` ignores zero-step records. `REALAGY_TRACE_USAGE=1` writes `~/.pi/agent/realagy/usage-trace.jsonl`.

Tools and Esc: pi-bridge advertises every model-facing Pi tool plus active tools; dispatch still permits only currently active tools (except polling). On `session_tree`, `treeRestoreExtras()` deactivates situational tools not declared by the branch. Already-aborted streams finish aborted without planning; parked calls, including escalated calls, are failed on abort.

Verification: `npm run check` passed 23 files/169 tests, including official Linux/macOS/Windows context-unlock vectors; `npm run smoke:pi` and live Gemini ACP smoke passed. Commit `3a1828c` is on `origin/main`.
