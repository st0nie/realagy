realagy's `agy-background` message renderer (`src/background-card.ts`) deliberately copies realtasks' notification card (`~/Workspaces/realtasks/src/ui.ts` renderNotification): one Box per message with `toolSuccessBg`/`toolErrorBg`, padding `(outputPad, 1)`, per-item header `✓ agy <kind> <label accent> · exit N · dur` (muted detail), collapsed = last 5 output lines (CARD_PREVIEW_LINES) under muted `... (N earlier lines, ctrl+o to expand)`, expanded adds a muted command line (`$ cmd` for run_command, `tool target` otherwise, title for subagents), full output and `log:` path. Wrapped in pi-tui `MouseRegion`: left click toggles; state kept in a WeakMap keyed by the message object with `{base, expanded}` and dropped when global ctrl+o state differs from `base`. Click works only in pi fullscreen mode. BackgroundNotice no longer has a `tail` field (card slices `output`). Keep both projects' card styles in sync when changing either.
