`src/transcript.ts` fresh replay retains trailing pi-lens ephemeral user injections together with their current user message (so the current image is no longer lost when an injection follows the image message) and attaches retained historical user/tool-result images before current images, using chronological numbered references. Historical replay is capped at 20 images and 20 MiB decoded data, choosing newest first; the model-visible transcript includes omission notices, and images from text-budget-omitted messages are not sent. Warm turns send only the delta, and the fresh fallback carries historical images.

Live tests against agy 1.5.3 / gemini-3.8-flash covered the current injected image, a historical user image, a historical tool-result image, and old+new two-image ordering (codes Q7M42 and R8N53). A Pi CLI end-to-end direct image test with -nt and low effort returned Q7M42; another with default tools returned Q7M42 after 61 seconds.
