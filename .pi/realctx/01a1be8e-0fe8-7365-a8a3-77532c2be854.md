`src/acp/context-unlock.ts` is a TypeScript port of DSH's agy context unlock; `src/acp/go-symbols.ts` resolves Go functions from `pclntab` for ELF, PE32+, and Mach-O without Python. `src/acp/derived-agy.ts` applies `contextUnlock` (from `noAutoCompaction`) and `fullMcpOutput` to the same in-memory source, then signs once on macOS, SHA-256 verifies, atomically caches, and prunes older derivatives. The installed agy and `PATH` are never modified. Gates 1/2/3A/3B/4A/4B expose context choices, remove the 256K checkpoint ceiling/override, and disable USER_INPUT 64K-token serializer clamps. Verified byte-for-byte against the Python reference for Linux x64 agy 1.5.2 (`8b19ca699b0d…`), macOS arm64 1.5.3 (`f1a643a70cb7…`), and Windows x64 1.5.3 (`605a3a6fa961…`); patches are idempotent. `REALAGY_AGY_FIXTURE_DIR` enables the optional official cross-platform test vectors. Implemented in commit `3a1828c`.
