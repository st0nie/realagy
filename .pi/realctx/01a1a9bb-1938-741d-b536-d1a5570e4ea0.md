`realagy` registers one slash command, `/realagy`, with `/realagy settings`, `/realagy setup`, and `/realagy usage` (`extensions/index.ts`); `/agy` was renamed to avoid naming collisions.

User configuration lives in `~/.pi/agent/realagy/config.json` (`src/settings.ts`, via `getAgentDir()`), not environment variables. `REALAGY_NO_COMPACT`, `REALAGY_CONTEXT_WINDOW`, `REALAGY_MAX_OUTPUT_TOKENS`, `REALAGY_AGY_PROFILE`, and `REALAGY_SETTINGS_FILE` were removed; only `AGY_BIN`, `GEMINI_HOME`, and `REALAGY_TRACE_USAGE` remain.

Defaults (`DEFAULT_REALAGY_CONFIG`): `noAutoCompaction: true` starts the loopback Cloud Code catalog proxy (`src/acp/catalog-proxy.ts`) and passes `--cloud_code_endpoint http://127.0.0.1:<port>` to `agy acp`, letting Pi handle compaction across each model's full context window. `agentProfile: true` runs `agy acp` with realagy's hidden Pi-only agent profile (`src/agent-profile.ts`). `contextWindow?: number` and `maxOutputTokens?: number` are omitted by default (model default); upstream catalog `maxTokens`/`maxOutputTokens` are captured by `CatalogProxy` before checkpointer rewriting, with `familyLimits` fallback (`src/models.ts`: Gemini 1,048,576 / 65,536; Claude 1,000,000 / 128,000; GPT-OSS 131,072 / 32,768).

`/realagy settings` renders `RealagySettingsComponent` (`SettingsList`, `SelectList`, `Input`, `DynamicBorder`) in TUI mode, falling back to `editRealagyConfigMenu` in RPC mode. It saves atomically (`0600`), re-registers Pi models immediately, and calls `driver.restart()` when `noAutoCompaction` or `agentProfile` changes. Under Bun, `undici`'s `ProxyAgent` shim has no `.close()` method, so `CatalogProxy.close()` guards `await closable.close?.()`.

Usage is fetched only when the user runs `/realagy usage`; there is no background quota polling or footer status. The command calls `agy --print /usage --output-format json` (~5–10 s), reading `command.data.groups[].buckets[]` fields `window`, `remaining_fraction`, and `reset_time` (groups `Gemini Models`, `Claude and GPT models`, `Gemini 4 Argon`). In TUI mode, it mounts `BorderedLoader` via `ctx.ui.custom` (`Loading Antigravity plan quota…` / `Checking Antigravity CLI…`), wires Esc and `session_shutdown` to an `AbortSignal` passed to `fetchCliUsage(bin, { signal })`, and calls `ctx.ui.notify` once after the query settles to avoid stale results flashing first. CLI fallback parses stdout on newline and resolves as soon as `parseCliUsage` succeeds, before `agy` finishes shutting down.

`UsageMeter` in `src/quota.ts` accumulates step usage and renders `report()`. Quota group headers are `<name> · <models>` (stripping `Models within this group:`); `Current session (5h)` precedes `This week`. The 25-character `━`/`─` bar has right-aligned `<X>% used`, rounded up to `0.1%` so nonzero usage never reads `0% used`. Labels are `Starts with your first message` (unused 5h), `Quota available` (other unused), `Quota exhausted`, or `Resets <today|tomorrow|Weekday> HH:MM (in Xd Yh|Xh Ym|Xm)`.

Gemini 4 Argon `/usage` data was observed to be stale/server-cached (measured 2026-11-05, 12:02–12:09): three prompts confirmed to run on Argon did not show an Argon weekly-bucket drop. Idle polls alternated between stale snapshots; this also occurs with plain `agy`, so it is server-side quota accounting/caching, not a realagy bug. Poll `/usage` several times and compare.

Usage docs follow `forgejo.wolf109909.top/webj8/webjet` (webjet structure) and live in `README.md` (docs table, install, commands, layout), `docs/architecture.md`, and `docs/development.md`. `AGENTS.md` and `CHANGELOG.md` were removed; do not recreate them or a changelog.
