Live A/B with agy 1.5.1 (probe /tmp/agyprobe/pitools.mts): a policy in `_meta.antigravity.systemPrompt.append` that only says 'prefer pi tools' left GPT-OSS 120B mixing native run_command/read_file/write_file (writes via pi in 1/3 runs). Explicitly saying 'Do not use your built-in run_command, read_file, write_file, edit_file or list_dir tools for anything a pi tool can do' plus 'run every shell command (including directory listings) with them' made GPT-OSS use pi read/bash/write in 3/3 pi runs (only an occasional opening native `ls`). Gemini 3.8 Flash and Claude Sonnet 5.5 follow either wording. Wording lives in src/tool-policy.ts.
