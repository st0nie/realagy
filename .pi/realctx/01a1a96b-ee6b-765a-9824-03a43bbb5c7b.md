Useful references for realagy: (1) github.com/zacbemis/pi-antigravity-acp-provider (npm pi-antigravity-acp-provider) reuses a WARM ACP session per pi session (persisted in ~/.pi/agent/antigravity-acp-provider/sessions.json), validates it with a sha256 fingerprint of the first `messageCount` pi messages plus tool/mode fingerprints, sends only the new user message or an "external-delta" resource, and rebuilds a fresh session with a bounded (32k chars) history resource on divergence. (2) github.com/simonepri/refined-antigravity-acp is a hardening proxy around agy_acp_server.par documenting upstream defects (orphaned SQLite checkpoints, loop detection, clientInfo zed gating, usage metrics). realagy instead opens a fresh ACP session per user turn and replays the whole pi transcript as a `pi://transcript` resource.
