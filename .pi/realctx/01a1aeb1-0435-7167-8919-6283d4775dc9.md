- When GPT-OSS emits a malformed tool call, agy sends an `agent_message_chunk` with exactly `\n⚠ Model produced invalid output.\n` and retries; realagy renders it as thinking (src/acp/events.ts isAgyRetryNotice).
- Native read_file `tool_call` (in_progress) and its `completed` update arrive in the same instant (reported after execution), so measured durations are ~0; run_command reports real time (in_progress → pending → permission → in_progress → completed). realagy hides durations < 100 ms.
- Before echoing each prompt as `user_message_chunk`, agy sends `config_option_update` and `available_commands_update` frames (plus leftovers of finished background work). realagy holds only content frames (message/thought/tool_call/tool_call_update) until the echo.
- Background notice live-verified: agy writes brain/<sessionId>/.system_generated/messages/<id>.json ~when the task ends; messageTitle e.g. 'Sleep and echo finished finished' (agy's own wording).
